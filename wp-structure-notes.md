## wp-admin
-the code that runs into the dashbord-you dont edit this

## wp-content
-Where plugins-themes-uploads are stored-you can work on it
-themes-design of the site
-plugins-addon features for the site
-uploads-any image or file uploaded is stored here

## wp-includes
-The core engine of wordpress with main functions and libraries-you dont edit this

## wp-config.php constants
-The main setting file of site
-DB_NAME-Name of the Database 
-DB_USER and DB_PASSWORD: the login WordPress uses to access the database
-DB_HOST:Where Database is located
-$table_prefix: the starting word of all the database table names
-WP_DEBUG: when true, WordPress shows errors and warnings. It should be on while developing and off on a live site.
-AUTH_KEY and the other keys/salts: random strings that make login cookies harder to forge.
